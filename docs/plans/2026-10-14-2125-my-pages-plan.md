# My pages

## Goal

A person with an ArtifactSmith token can open a private catalog of that token's workspace in a browser, sign out, and read versions and build jobs. The page is read-only.

## Settled decisions

1. `/app/` is on the API origin (port 8780). The preview origin stays cookieless and does not serve `/app/`.
2. Sign-in is a paste form. The token is hashed and checked against `tokens`. The cookie value is a random session id. SQLite stores `sha256(cookie)` and the token id, never the token. The token is not placed in the URL.
3. Cookie flags: HttpOnly, SameSite=Strict, Path=/app. Secure when `AM_API_URL` is https, or when `AM_COOKIE_SECURE` forces it. Local HTTP quickstart stays usable because browsers drop Secure cookies on `http://127.0.0.1`.
4. Every request reloads the token. `revoked_at`, expiry, or a missing `read` permission deletes the session immediately.
5. The list is that workspace only. An artifact id from another workspace, or an unknown id, is 404. There is no workspace switcher.
6. Login and sign-out are POST forms with a CSRF check. Login also binds a signed token to an HttpOnly cookie. Search is a GET and does not change state.
7. Failed logins are counted per peer IP in SQLite (`AM_LOGIN_LIMIT` 8 per `AM_LOGIN_WINDOW_S` 900). The submitted token is not stored. `X-Forwarded-For` is not trusted.
8. List fields: title, format, style, latest version, status, updated time, and the floating public share link or the text "not shared". Search matches title or slug. `%` and `_` are literal. Status filters the latest version.
9. Detail shows each version and its job: status, duration, the check text stored on the job error, and the note (version summary, otherwise job progress).
10. No new libraries. Cookies and HMAC use Starlette and the stdlib. A later hosted trial calls `start_session` with a token it minted. This release does not add accounts.

## Check

Auth, CSRF, rate limit, revoke, cross-workspace 404, search, status filter, and cookie flags are unit-tested. Phone layout is the house palette in one column, checked at 390px.
