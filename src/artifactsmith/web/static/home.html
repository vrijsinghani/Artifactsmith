The problem

ArtifactSmith gives your own agents a real page you can look at, share, and pull back later, on your own server.

Meta's Muse artifacts showed a better way: the agent hands you a real page you can look at, share, and pull back later.

How it works

Four steps take an agent request from private build to revocable share link.

01

Create

The agent calls create with the user's request (verbatim_request) and its notes (source_content or source_files). ArtifactSmith writes and renders the document. The build is private. For a finished page, publish stores it with no model call.

02

Edit

edit makes a new version from the latest one. Every artifact is versioned.

03

Share

share creates a public /s/ link for one exact version.

04

Unshare

unshare makes that link return 404, any time.

Workspaces: tokens belong to one workspace and carry a permission set (create, read, edit, publish, export, share, delete). Knowing an artifact id from another workspace does not grant access. Tokens are stored as SHA-256 hashes.

Quickstart

Set up the server, then point your MCP client at the API and send the token as a bearer header.

cp .env.example .env
# Set OPENAI_API_KEY (or AM_LLM_KEY).
./scripts/ensure-local-env.sh
docker compose up -d --build
docker compose exec server artifactsmith token add --name agent --workspace alpha

Then point your MCP client at {AM_API_URL}/mcp (API port 8780) and send the token as a bearer header:

URL:    {AM_API_URL}/mcp
Header: Authorization: Bearer <your-token>

Works with any OpenAI-compatible model endpoint (default model gpt-4o-mini). Published image: ghcr.io/vrijsinghani/artifactsmith:0.1.0 (linux/amd64).

FAQ

How is it different from other self-hosted artifact servers?

Most publish HTML or Markdown the agent already wrote. ArtifactSmith takes the request plus the agent's sources and does the writing and rendering itself, adds named styles, PDF/DOCX/XLSX output and per-workspace tokens.

Is my content private?

Yes. Builds stay private until you call share, and unshare kills the link. The process sends no usage data anywhere.

Which clients work?

Any MCP client: Claude Code, Codex, OpenCode, Hermes and others.

What does it cost?

It's free and MIT-licensed. You pay only for your own model calls and hosting.

Is it secure?

Preview pages run on their own cookieless origin; private-network links and likely secrets fail the build. It went through an independent audit (Semgrep, Bandit, gitleaks, pip-audit, Trivy) and a written threat model.
